#Project Overview

This project is an AI-powered Career Guidance Chatbot built using the n8n automation platform and OpenAI GPT.
The chatbot helps users explore career options and answers frequently asked questions using structured data stored in Google Sheets.

The system uses an AI Agent to process user queries, retrieve relevant information from Google Sheets, and generate intelligent responses using the GPT model. It also includes memory functionality to maintain conversation context.

This project demonstrates how AI-powered chatbots can be developed using no-code/low-code tools without building a traditional website.
